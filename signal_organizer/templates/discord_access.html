Getting messages out of Discord

This app does not connect to Discord. It never asks for your Discord password, session cookie, or user token. Automating a personal account ("self-bot") or reading a user token breaks Discord's Terms of Service and can get the account banned.

If you are only a member of the server

Discord gives members no documented way to read a channel's messages programmatically. Your options:

  • Copy and paste alerts into the Import page.
  • Ask a server admin for an export made with their own bot, or ask them to add a bot that writes alerts to a file you can import.
  • Follow an Announcement channel. If the alert channel is an Announcement channel, Discord lets you follow it into a server you own. A bot you add to your own server could then read those copies. This app does not include that bot yet.

If you own or admin the server

A Discord bot with the Message Content intent, added with the permissions you choose, is the documented route. This app does not include one. Adding it would be an external account connection, so it is not built without your approval.

Discord's "Request my data" package

That export contains messages you sent, not other people's alerts, so it rarely helps here.
