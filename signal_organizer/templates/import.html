Paste messages

Copy alert text from Discord and paste it here. Separate messages with a line containing only ---. Optionally start a message with its time in brackets, e.g. [2026-10-09 09:31] BTO $ACME 50C 10/16 @ 1.20. Without a time, the message timestamp is stored as UNKNOWN. Quote lines with > to mark quoted text.

Import a file

JSON or CSV, up to 5 MB and 5,000 messages. Only import exports you are authorized to have (for example, a server admin's bot export). See Discord access.

Accepted formats

JSON: a list of objects, or {"messages": [...]}. Each object needs content (or text/message). Optional: timestamp, id, author (string or object with name), channel, and reference/reply_to to mark replies.

CSV: a header row with a content column, plus any of timestamp, id, author, channel, reply_to.

Examples with fictional data are in the examples/ folder.
